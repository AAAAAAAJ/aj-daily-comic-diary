# 输出目标适配

## 选择

运行前读取配置中的 `target.platform`：

- `feishu`：使用 lark-cli 和飞书文档 token。
- `dingtalk`：使用已配置的钉钉文档连接器或 dingtalk CLI；保存文档 URL、文档 ID 和图片资源 ID。
- 未指定时沿用当前项目已有目标，不自动创建第二份文档。

## 共同结构

两个平台都使用：日期标题、覆盖范围与风格、当日图卡、2—3句简述、可选观察和来源。最新日期在引言后。每次写入后重新读取目标文档，核对日期唯一、图片位置、图片资源 ID 和来源链接。

## 平台差异

飞书支持 block ID、图片 token 和局部移动；写入后记录 `revision_id`。钉钉接口名称、图片资源字段和局部更新能力以当前 CLI 或连接器帮助为准；先探测能力，再选择局部更新或安全追加。钉钉能力缺失时保留本地 XML 与图卡，状态标记 `target_pending`，不伪造成功。

禁止同时向两个平台写入，除非用户明确要求双写。平台切换时保留同一份事实和图卡，新增目标文档章节，不重复取证。
